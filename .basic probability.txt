### 1. Basic probability

*Question:* A fair die is rolled once. Find probability of obtaining a number less than 3.

*Step 1:* Total outcomes = $\{1,2,3,4,5,6\} = 6$

*Step 2:* Favourable outcomes less than 3 = $\{1,2\} = 2$

*Step 3:* Formula $P = \frac{\text{Favourable}}{\text{Total}}$
P = \frac{2}{6} = \frac{1}{3} \approx 0.333
*Answer: 1/3*

### 2. Complement

*Question:* A group contains 15 DA and 10 FS students. One student selected at random. Find probability that student is not from DA.

*Step 1:* Total = $15 + 10 = 25$

*Step 2:* $P(\text{DA}) = \frac{15}{25} = \frac{3}{5}$

*Step 3:* $P(\text{Not DA}) = 1 - P(\text{DA})$
P = 1 - \frac{3}{5} = \frac{2}{5} = 0.4
*Answer: 2/5*
Direct ga chesina kuda same: $P = \frac{10}{25} = \frac{2}{5}$

### 3. Addition rule

*Question:* A fair die is rolled once. Find probability of obtaining an odd number or a number greater than 4.

*Step 1:* Let A = Odd, B = $>4$
$A = \{1,3,5\}$, $P(A) = \frac{3}{6}$
$B = \{5,6\}$, $P(B) = \frac{2}{6}$

*Step 2:* Overlap $A \cap B = \{5\}$, $P(A \cap B) = \frac{1}{6}$

*Step 3:* $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
P = \frac{3}{6} + \frac{2}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}
*Answer: 2/3*

### 4. Exactly one

*Question:* A fair coin is tossed twice independently. Find probability of exactly one head. List successful sequences.

*Step 1:* Sample space = $\{HH, HT, TH, TT\} = 4$

*Step 2:* Exactly one head = $\{HT, TH\} = 2$
P = \frac{2}{4} = \frac{1}{2} = 0.5
*Answer: 1/2*

### 5. At least one

*Question:* A fair coin is tossed four independent times. Find probability of at least one head using complement rule.

*Step 1:* Use complement: $P(\text{at least one head}) = 1 - P(\text{no head})$

*Step 2:* No head means all tails = $TTTT$
$P(TTTT) = \left(\frac{1}{2}\right)^4 = \frac{1}{16}$

*Step 3:*
P = 1 - \frac{1}{16} = \frac{15}{16} = 0.9375
*Answer: 15/16*

### 6. Overlapping card events

*Question:* One card is drawn uniformly from standard 52-card deck. Find probability that it is a queen or a spade.

*Step 1:* $P(\text{Queen}) = \frac{4}{52}$
$P(\text{Spade}) = \frac{13}{52}$

*Step 2:* Overlap = Queen of Spade = 1 card
$P(\text{Queen} \cap \text{Spade}) = \frac{1}{52}$

*Step 3:* $P = \frac{4}{52} + \frac{13}{52} - \frac{1}{52} = \frac{16}{52}$
P = \frac{4}{13} \approx 0.3077
*Answer: 4/13*

### 7. Without replacement

*Question:* Two cards are drawn from a standard deck without replacement. Find probability that both are kings.

*Step 1:* First card King: $P_1 = \frac{4}{52}$

*Step 2:* Second card King, one king already gone, one card less:
$P_2 = \frac{3}{51}$

*Step 3:* Multiply because sequential:
P = \frac{4}{52} \times \frac{3}{51} = \frac{12}{2652} = \frac{1}{221} \approx 0.00452
*Answer: 1/221*

### 8. Independent experiments

*Question:* A fair coin is tossed and a fair die is rolled independently. Find probability of tails and a number greater than 4.

*Step 1:* $P(\text{Tails}) = \frac{1}{2}$

*Step 2:* Die $>4$ = $\{5,6\}$, $P = \frac{2}{6} = \frac{1}{3}$

*Step 3:* Independent so multiply:
P = \frac{1}{2} \times \frac{1}{3} = \frac{1}{6} \approx 0.1667
*Answer: 1/6*

### 9. Explain the relationship

*Question:* Explain why roll a 1 and roll a 6 on the same die roll are mutually exclusive but not independent.

*Step 1 - Mutually Exclusive:* Both cannot happen together.
$P(1 \cap 6) = 0$ because one roll gives only one number.

*Step 2 - Independent check:* For independent, $P(A \cap B)$ should be $P(A)P(B)$.
Here $P(1) = \frac{1}{6}$, $P(6) = \frac{1}{6}$
$P(1)P(6) = \frac{1}{36}$

*Step 3:* $0 \neq \frac{1}{36}$, so NOT independent.


### 10. Python extension

*Question:* Modify the three-toss simulation to estimate probability of exactly two heads. Give its theoretical probability and explain which condition changes.

*Step 1 - Theoretical:* For 3 tosses, sample space = 8
Exactly two heads = $\{HHT, HTH, THH\} = 3$
P = \frac{3}{8} = 0.375
*Step 2 - What changes in code?*
Only the condition for counting success changes. From `count == 3` or `count == 1` to `count == 2`.

*Step 3 - Python Code:*
import random

N = 10000
success = 0

for _ in range(N):
    tosses = [random.choice(['H','T']) for _ in range(3)]
    heads = tosses.count('H')
    if heads == 2:  # <-- ONLY THIS CONDITION CHANGES
        success += 1

print("Estimated P =", success / N)
print("Theoretical P = 3/8 =", 3/8)
*Step 4 - Output:* Estimated will be around $0.375$, close to $0.375$ when N is large.
